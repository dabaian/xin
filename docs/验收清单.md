## A. 账号与权限

| # | 操作 | 预期 |
|---|---|---|
| A1 | 注册 → 登录 → 刷新页面 | 会话保持，顶栏余额显示 20（新用户赠送） |

## B. 计费与账本

| C1d | 自定义金额填 200 → 点「充值 ¥200.00」 | 试算行显示「到账 2,200 积分（含赠送 200 · 赠 10%）」 |

| C1f | 自定义金额填 20001 | 红字「单笔最高 20000 元」，按钮置灰 |
| C1g | 自定义金额填 500，接口直接传 `custom_yuan=9` | 400「自定义充值不能低于 10 元」，不产生订单 |
| C2 | 真扫码支付 | 页面 2–3 秒内自动变「充值成功」，余额 +100 |
| C3 | 支付后立即关页面，再进钱包 | 余额已到账（后台扫单补记） |
| C4 | 同一 `notify` 重放 10 次 | 只入账一次 |
| C5 | 篡改通知里的 `total_amount` | 验签失败或金额比对失败，不入账 |
| C6 | 用别人账号的订单号查状态 | 404 |
| C7 | 二维码过期（30 分钟） | 状态变「已过期」，不能支付 |
| C8 | 登录后访问 `/api/payments/channels` | 返回当前生效通道；生产环境 `mock` 必须为 `false` 且通道列表里没有 `mock` |
| C9 | 不配商户参数且 `PAYMENT_CHANNEL` 留空 | 钱包页提示「收款通道未配置」，输入框和按钮置灰，下单返回 503，不会静默走模拟 |
| C9b | `APP_ENV=prod` + `ALIPAY_MOCK=1` 启动 | **进程直接退出（退出码 2）**，终端列出「生产环境禁止模拟支付」 |
| C9c | 生产环境 `POST /api/payments/mock-pay/x` | 404（这条路由根本没注册） |
| C9d | 生产环境访问 `/api/docs` | 404（API 文档在生产环境自动关闭） |
| C10 | 前后端分离：`CORS_ORIGINS` 只填前端域名 | 前端能正常调接口；换别的来源预检被拒（400） |

## 上线前最后三道闸

1. `ALIPAY_MOCK=0`，`ALIPAY_APP_ID` 是生产应用
2. `PUBLIC_BASE` 是 https 外网域名（否则图生视频一定失败）
3. 管理员密码不是默认值，`.env` 权限 600
