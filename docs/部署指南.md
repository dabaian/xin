# 部署指南

面向「自己有服务器、要把平台真正跑起来」的场景。以 Ubuntu 22.04 + 阿里云/腾讯云轻量为例，Nginx + systemd + 本地 SQLite。

---

## 0. 前置条件

| 项 | 要求 |
|---|---|
| 服务器 | 2 核 4G 起步（号池在同一台时建议 4 核 8G，Chromium 吃内存） |
| 系统 | Ubuntu 20.04+ / Debian 11+ / CentOS Stream 9 |
| 域名 | 已备案（大陆服务器），解析到服务器 IP |
| 端口 | 80 / 443 放行 |
| 号池 | `muse2api` 已能出片（先自己用 `curl` 验证过再往下走） |

先验证号池是通的（在服务器上执行）：

```bash
curl -s -H "Authorization: Bearer 你的MUSE_KEY" http://127.0.0.1:18610/healthz
curl -s -H "Authorization: Bearer 你的MUSE_KEY" http://127.0.0.1:18610/v1/models
```

两条都返回 JSON 才继续。

## 1. 上传代码

```bash
# 本地打包（排除虚拟环境、数据、日志）
tar --exclude='data' --exclude='venv' --exclude='.git' --exclude='__pycache__' \
    -czf yice-muse.tar.gz yice-muse
scp yice-muse.tar.gz root@你的服务器:/root/
ssh root@你的服务器
mkdir -p /root/src && tar -xzf yice-muse.tar.gz -C /root/src
```

---

## 2. 一键安装

```bash
cd /root/src/yice-muse
sudo bash deploy/install.sh your-domain.com
```

脚本做的事（可逐段阅读，别盲跑）：

1. 装 `python3-venv` / `nginx` / `curl`
2. 建系统用户 `muse`，目录 `/opt/viora-ai`
3. 复制 `backend` / `frontend` 到 `/opt/viora-ai`
4. 生成 `.env`（随机管理员密码）、`secrets/`、`releases/`、`logs/`
5. venv + 依赖
6. `systemd` 服务 `viora-ai`（监听 `127.0.0.1:8080`）
7. Nginx 反代（含支付回调不缓冲、长任务超时 900s、静态资源 7 天缓存）
8. 有 certbot 就自动签证书，没有会打印命令

装完看状态：

```bash
systemctl status viora-ai --no-pager
curl -s http://127.0.0.1:8080/healthz
curl -s http://127.0.0.1:8080/readyz   # 会连号池，返回 503 说明号池没通
```

## 3. 补配置

```bash
sudo nano /opt/viora-ai/.env
```

必须改的四项：

```ini
PUBLIC_BASE=https://your-domain.com

MUSE_BASE=http://127.0.0.1:18610
MUSE_KEY=号池的 API Key

ALIPAY_APP_ID=2021xxxxxxxxxxxx
ALIPAY_PRIVATE_KEY_PATH=/opt/viora-ai/secrets/alipay_private_key.pem
ALIPAY_PUBLIC_KEY_PATH=/opt/viora-ai/secrets/alipay_public_key.pem
ALIPAY_NOTIFY_URL=https://your-domain.com/api/payments/notify
ALIPAY_MOCK=0
```

密钥文件：

```bash
sudo mkdir -p /opt/viora-ai/secrets
sudo nano /opt/viora-ai/secrets/alipay_private_key.pem   # 粘贴应用私钥，含头尾
sudo nano /opt/viora-ai/secrets/alipay_public_key.pem    # 粘贴支付宝公钥
sudo chmod 600 /opt/viora-ai/secrets/*.pem
sudo chown -R muse:muse /opt/viora-ai/secrets
sudo systemctl restart viora-ai
```

> 私钥是「应用私钥」（你生成的），公钥是「支付宝公钥」（从开放平台复制，**不是**你上传的应用公钥）。
> 这两个搞反了会报 `sign check fail`，详见 `支付宝接入.md`。

## 4. 首次登录与初始化

1. 打开 `https://your-domain.com`，用 `.env` 里的 `ADMIN_USERNAME / ADMIN_PASSWORD` 登录
2. 进「管理后台 → 上游通道」：
   - 填 `MUSE_BASE` 和密钥（如果没写在 `.env` 里），点保存
   - 点「连通性测试」，显示 ✓ 上游可达
3. 「价格规则」核对：1080p 5 秒 10 积分 / 10 秒 20 积分，2K 为两倍，图片 5 积分
4. 退出管理员，注册一个普通账号走一遍：生成 → 充值 → 下载

## 5. 桌面客户端分发

```bash
# 本地 Windows 上
cd desktop && build.bat

# 把安装包传到服务器
scp installer_out/VioraAI-Setup.exe root@服务器:/opt/viora-ai/releases/
```

服务器上：

```bash
sudo chown muse:muse /opt/viora-ai/releases/VioraAI-Setup.exe
```

`.env` 里对应：`DESKTOP_VERSION=2.0.0`、`DESKTOP_SETUP_NAME=VioraAI-Setup.exe`。
发布新版本时改 `DESKTOP_VERSION` 再重启，客户端启动会检测到并提示升级。

改客户端 `config.json` 的 `url` 为 `https://your-domain.com/studio` 后再打包（这个文件跟 exe 同目录，也可以装完直接改）。

## 6. 日常运维

```bash
systemctl restart viora-ai        # 改完 .env 必重启
tail -f /opt/viora-ai/logs/app.log
journalctl -u viora-ai -n 100 --no-pager
```

**备份**（建议加到 crontab，每天 3 点）：

```bash
0 3 * * * tar -czf /opt/backup/muse-$(date +\%F).tar.gz \
  /opt/viora-ai/data/studio.db* /opt/viora-ai/data/media \
  && find /opt/backup -name 'muse-*.tar.gz' -mtime +14 -delete
```

SQLite 用的是 WAL，备份要连 `-wal` / `-shm` 一起拷，或者用：

```bash
sqlite3 /opt/viora-ai/data/studio.db ".backup /opt/backup/studio-$(date +%F).db"
```

**扩容**：先看 `data/` 目录体积；成片占空间最快，按需加清理任务（`media_assets.expires_at` 已预留）。

## 7. 常见故障

| 现象 | 原因 / 处理 |
|---|---|
| `readyz` 返回 503 | 号池没通：检查 `MUSE_BASE` 端口、`MUSE_KEY`、号池进程 |
| 提交后一直「排队中」 | 号池并发满了，或账号池里没有可用账号；看号池后台 |
| 任务卡 `待对账` | 上游说完成却没成品，或超过 45 分钟；后台可人工退款/重试 |
| 图生视频失败，报取不到参考图 | `PUBLIC_BASE` 不是外网 https，号池下载不到签名链接 |
| 充值二维码出不来 | 支付宝未配置或 `ALIPAY_MOCK=0` 且缺密钥，看 `/api/payments/selfcheck` |
| 扫码付了但没到账 | 回调没通：确认 `ALIPAY_NOTIFY_URL` 公网可达、Nginx 那段 `notify` 配置存在。系统每 45 秒主动查单兜底，最多等 1 分钟 |
| 登录一直 429 | 触发了登录限速（5 分钟 8 次），等一会儿或清 `sessions` 表 |

## 8. 安全清单

- [ ] `chmod 600 /opt/viora-ai/.env`
- [ ] 支付宝密钥文件 `600`，属主 `muse`
- [ ] `ALIPAY_MOCK=0`
- [ ] 管理员密码不是默认值
- [ ] 只监听 `127.0.0.1:8080`，外面套 Nginx + HTTPS
- [ ] 号池 `18610` 端口不要暴露公网（只允许本机/内网）
- [ ] 云厂商安全组只放 22 / 80 / 443
