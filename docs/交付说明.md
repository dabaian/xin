## 二、定价口径（已写进代码和数据库）

| 项目 | 积分 | 折算 |
|---|---|---|
| 充值 | 1 元 = 10 积分 | — |
| 图片 | 5 积分 / 张 | 0.5 元 |
| 5 秒视频 1080p（默认） | 10 积分 | 1 元 |
| 10 秒视频 1080p | 20 积分 | 2 元 |
| 15 / 20 / 30 秒 1080p | 30 / 40 / 60 积分 | 2 积分/秒线性 |
| **2K 超清（全时长）** | **上表 × 2**（5 秒 20、10 秒 40） | 双倍积分 |

清晰度默认 1080p，可选 2K；2K 消耗 1080p 的两倍积分。档位定义在
`backend/app/config.py` 的 `RESOLUTIONS`，加新档位只要加一行，重启后价格表自动补齐。

套餐（可在后台「价格规则」或 `.env` 的 `RECHARGE_PACKAGES` 改）：

| 套餐 | 本金 | 赠送 | 到账 | 价格 |
|---|---|---|---|---|
| 体验包 | 100 | — | 100 | 10 元 |
| 基础包 | 500 | — | 500 | 50 元 |
| 标准包 | 2,000 | +200（10%） | 2,200 | 200 元 |
| 专业包 | 5,000 | +750（15%） | 5,750 | 500 元 |
| 工作室包 | 10,000 | +2,000（20%） | 12,000 | 1,000 元 |
| 企业包 | 20,000 | +4,000（20%） | 24,000 | 2,000 元 |

**赠送规则（三档，唯一来源 `config.py` 的 `BONUS_TIERS`）**：

| 单笔充值 | 赠送 |
|---|---|
| 不足 200 元 | 不赠 |
| 200 ~ 499 元 | 10% |
| 500 ~ 999 元 | 15% |
| 1000 元及以上 | 20% |

**自定义充值**：钱包页有「自定义金额」，最低 10 元、最高 20,000 元，输入即实时试算，
赠送走同一套三档规则（`GET /api/wallet/custom-quote` 试算、`POST /api/payments/checkout`
传 `custom_yuan` 下单）。金额与积分全部由服务端换算，前端传的价格字段一律不采信。

**计费铁律**：提交先冻结 → 成品落盘才结算 → 失败原路退回。上游超时不等于失败，只查单不重提。

## 三、你只需要给我这 3 样东西

| # | 参数 | 从哪拿 | 填到哪 |
|---|---|---|---|
| 1 | **域名** | 你已有的域名，解析一条 A 记录到服务器 IP | `.env` 的 `PUBLIC_BASE`（必须 https，且外网真能打开） |
| 2 | **号池地址 + Key** | 你现在 `muse2api` 服务监听在哪 + 它的 `MUSE_KEY` | `.env` 的 `MUSE_BASE` / `MUSE_KEY`（同机就填 `http://127.0.0.1:18610`） |
| 3 | **支付宝 APPID + 两个密钥** | 支付宝开放平台 → 创建应用 → 签约「当面付」→ 生成密钥 | `.env` 的 `ALIPAY_APP_ID`，两个 `.pem` 放 `secrets/` 目录 |

> **第 3 项不齐就别急着上线收款**：没有商户参数时，钱包页会显示「收款通道未配置」，
> 下单接口返回 503，不会生成假二维码。想先把站跑起来、暂时不收钱，就写
> `PAYMENT_CHANNEL=none`；等签约下来填好密钥、把这行删掉重启即可。

**关于支付宝的两个密钥，别搞混**（文档里踩坑章节写了）：

- **应用私钥**：你自己生成，只有你有 → `alipay_private_key.pem`
- **应用公钥**：上传到支付宝开放平台的那个
- **支付宝公钥**：从开放平台**复制**下来的那个 → `alipay_public_key.pem`

代码里验签用的是**支付宝公钥**，填成应用公钥会导致「支付成功但余额不加」。

## 四、上服务器（5 步）

```bash
# 1. 上传代码（在你本机执行，替换成你的服务器）
scp -r yice-muse root@你的服务器IP:/tmp/

# 2. 一键安装（在服务器执行）
cd /tmp && sudo bash yice-muse/deploy/install.sh 你的域名.com
#    脚本会：建 muse 用户 / 建目录 / 装 venv 依赖 / 写 systemd / 配 Nginx /
#            生成 .env 和随机管理员密码 / 尝试签 Let's Encrypt 证书

# 3. 补三样配置
sudo -u muse nano /opt/viora-ai/.env      # 改 PUBLIC_BASE / MUSE_BASE / MUSE_KEY / ALIPAY_*
sudo mkdir -p /opt/viora-ai/secrets && sudo chmod 700 /opt/viora-ai/secrets
# 把两个 pem 传上去，chmod 600
sudo chmod 600 /opt/viora-ai/secrets/*.pem

# 4. 重启
sudo systemctl restart viora-ai
sudo systemctl status viora-ai --no-pager

# 5. 自检（3 个都要对）
curl https://你的域名.com/healthz          # {"ok":true,...}
curl https://你的域名.com/readyz           # 会顺带探号池，探通才返回 ok
# 用管理员登录后，在浏览器打开 /admin → 概览页，右上「支付宝自检」应为绿色
```

装完的管理员账号密码在 `/opt/viora-ai/.env` 里（`ADMIN_USERNAME` / `ADMIN_PASSWORD`），脚本生成的是随机强密码，**登录后第一件事改掉**。

## 五、上线后照这个顺序点一遍

| 顺序 | 操作 | 预期 |
|---|---|---|
| 1 | 注册一个新号 | 自动送 20 积分 |
| 2 | 钱包 → 选体验包 → 出二维码 | 真模式下用支付宝扫，付 10 元 |
| 3 | 付款后回页面 | 余额 +100，流水出现「充值入账」 |
| 4 | 工作台 → 生成图片 → 填提示词 | 显示「5 积分」，提交后余额 -5 冻结 |
| 4.5 | 工作台 → 清晰度切 2K | 成本立刻翻倍（5 秒 10 → 20），下方提示「2K 双倍计费」 |

## 九、三个最容易踩的坑

**1. `PUBLIC_BASE` 必须是外网能打开的 https 地址**
图生视频时，号池要拿这个域名去下载参考图。填 `127.0.0.1` 或内网 IP，参考图会 404，任务会失败但错误信息看起来像号池的锅。

**2. Nginx 不能拦掉 `/api/payments/notify`**
支付宝异步通知打的是这个路径，它不带 Cookie，`Content-Type` 是表单不是 JSON。现有 `nginx.conf` 已经放行，但如果你自己改过 Nginx，务必确认这个路径没被防盗链或 UA 规则挡住——挡了的表现是「用户付了钱，余额不加」。

**3. 模拟开关在 `APP_ENV=prod` 下会让服务起不来**

这一版把「漏改一行配置」的口子做成了代码级检查（`backend/app/guard.py`）：
生产环境下 `ALIPAY_MOCK=1`、`MAIL_ECHO=1`、`PAYMENT_CHANNEL=mock` 任意一项还在，
进程会直接退出并列出要改哪几行，不会带着漏洞跑起来。所以「忘了关」这件事，
现在表现为「起不来」而不是「白送积分」——看到启动失败先去终端读那段提示。
